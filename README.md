## 👨‍💻 About this repository

This repository documents my journey through **Harvard's CS50x 2026: Introduction to Computer Science**.

The goal is not only to complete the course, but to build strong foundations in programming, problem solving, algorithms, data structures and software development.

I am documenting my progress, challenges, solutions and projects as I develop my skills as a developer.

## 🎯 Learning Goals

* Understand fundamental computer science concepts
* Improve logical thinking and problem solving
* Learn how software works from the fundamentals
* Build real-world projects
* Create a strong foundation for future development in Web3 and Solidity
